# 🖥️ Operating Systems and System Administration – Practical Labs

This repository contains practical exercises, programming activities, Linux command-line exercises, and practical test work completed as part of the **IT2130 – Operating Systems and System Administration** module at the Sri Lanka Institute of Information Technology (SLIIT).

The practical sessions focus on C programming, process management, multithreading, inter-process communication (IPC), Linux commands, file permissions, and shell scripting.

## 🚀 Running C Programs

1. Install GCC or another compatible C compiler.
2. Open a terminal in the directory containing the C source file.
3. Compile the program:

```bash
gcc program.c -o program
```

4. Execute it:

```bash
./program
```

For programs using POSIX threads:

```bash
gcc program.c -o program -pthread
```

**Note:** These practical exercises use Linux/UNIX system calls and POSIX APIs. A compatible Linux environment is recommended.
